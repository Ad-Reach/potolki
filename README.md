# centro-plus.ru

Статический сайт «Центр Плюс — натяжные потолки».

- `data.py` — все данные: контакты, цены (пока черновые), тексты, акции, FAQ, статьи.
- `src/` — стили, скрипты, фото. `build.py` собирает сайт в `dist/`.
- `dist/` — готовый сайт, **хранится в репозитории**: после правок запустите `python3 build.py`
  и закоммитьте `dist/` вместе с исходниками (CI проверяет, что они совпадают).
- Пуш в `main` → Timeweb App Platform (Москва) видит готовый `dist/` и сразу выкладывает его,
  без установки Python и сборки на своей стороне.
- Настройки приложения App Platform — репозиторий `Ad-Reach/infra` (Terraform).

Локально: `python3 build.py && python3 -m http.server -d dist`.

## Работа с Claude Code

В репозитории настроен Claude Code (`CLAUDE.md`, `.claude/`). Что где:

- `CLAUDE.md` — правила проекта: команды, структура `data.py`, связь с `Ad-Reach/infra`, что нельзя трогать.
  Главное правило то же, что выше: после правки `src/`, `data.py` или `build.py` — `python3 build.py`
  и `dist/` в тот же коммит.
- Агенты (`.claude/agents/`, только чтение):
  - `explorer` — отвечает «где в проекте X» (контакт, цена, шаблон, фото);
  - `reviewer` — проверяет дифф: совпадение `dist/` с исходниками, ссылки, SEO-мета, доступность,
    адаптивность, незапрошенные изменения контактов и цен.
- Skills (`.claude/skills/`):
  - `/add-article` — добавить статью в `ARTICLES`;
  - `/update-content` — поменять контакты, акции, FAQ и т. п. в `data.py`;
  - `/release` — пересобрать, проверить `dist/` и закоммитить; запускается только вручную.
- Цены в `data.py` пока черновые. Claude меняет их только на значения, которые вы назвали сами,
  и не берёт цифры с других сайтов. Пустые поля (`max`, `email`, `legal`, отзывы) он не заполняет выдуманным.
- Настройки деплоя (ветка, домены, тариф) лежат в `Ad-Reach/infra`; из этого репозитория они не меняются.
